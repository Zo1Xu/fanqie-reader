# 隐私说明

最后更新：2026-09-17

fanqieReader 在用户本机运行，不运营中转服务器，也不加入自有遥测、广告或用户画像。

- 登录 Cookie 保存到 VS Code `SecretStorage`。
- 正文仅通过官网网页读取，公开章节匿名请求，受限章节尝试已保存的账号会话。字体资源不携带 Cookie。
- 最近 20 次网页正文读取的时间、匿名或账号模式、结果及错误分类仅保存在内存。用户主动执行“复制阅读诊断”时才写入剪贴板，不含 Cookie、账号标识、章节 ID、正文或原始异常文本。
- 当前版本不再创建或使用移动端访客状态，不启动移动端 SDK、Java 或模拟运行组件。旧版本保存的访客状态不再读取。
- 登录面板只在主动选择登录时显示，浏览器只在用户开始登录操作后启动。
- 阅读位置保存在 VS Code 扩展本地存储。
- 当前书架的书名、作者和章节数保存在 VS Code 扩展本地存储，用于避免每次启动都重新请求详情页。
- 手机号和短信验证码仅用于当前登录流程，不写入设置、工作区文件或项目日志。
- 密码只在番茄小说官方网页窗口中输入；扩展不读取或保存密码。
- 扩展直接访问 `fanqienovel.com` 及官方页面运行所需资源，以完成登录、书架和章节读取。
- 执行“退出登录”会清除登录 Cookie 和书架元数据缓存，但保留本地阅读进度。

项目作者不会通过自有服务器接收上述数据。番茄小说、VS Code、浏览器和操作系统会按照各自政策处理数据。

请勿在公开 Issue 中粘贴 Cookie、Token、手机号、验证码、完整 HAR、个人书架数据或含敏感信息的日志。
