# 0.7.11 网页会员读取与章节导航验证

2026-09-17。本版本已移除正式扩展的移动端读取入口及移动端运行组件打包，正文只通过官网网页读取。

## 真实会员响应复现

用户确认当前浏览器已登录会员。通过官网用户信息接口仅检查登录布尔值与会员布尔值，均为真；未导出账号 ID、Cookie 或正文。

对《十日终焉》第 11 章 `7175147347041911356`，在同一浏览器中分别请求匿名与账号网页，然后运行修改前的生产 `parseInitialState`：

| 模式 | 旧解析器结果 | 网页正文状态 |
| --- | --- | --- |
| 匿名 | 成功 | 锁定，HTML 长度 200 |
| 当前会员 | `INVALID_STATE` | 初始数据存在未加引号的 `undefined` |

对会员响应按字符串边界归一化 `undefined` 后，网页初始数据已包含完整正文，`isChapterLock=false`。动态正文接口也返回相同长度和未锁定状态。因此此前“必须接入动态接口才能读取本例会员正文”的判断不成立；已确认的本例缺陷是会员初始数据解析失败、可选账号重试吞掉异常。

修复仅将字符串外的 `undefined` 转为 JSON `null`，保留正文字符串，并继续使用 `JSON.parse` 拒绝函数调用、其他表达式及格式损坏的数据，不执行网页代码。

## 修改后读取结果

在当前会员浏览器中运行修改后的完整 `FanqieClient` 源码。传输适配器以浏览器 `credentials: include/omit` 分别对应账号和访客请求，使用合成会话标记；实际 Cookie 始终留在浏览器。对 Node 的 `Buffer` 和 `process` 提供浏览器适配。其余章节解析、账号重试、导航补全及字体读取使用生产代码。

| 章节 | 官网标注字数 | 实际段落文本字符数 | 段落 | 字体 | 结果 |
| --- | ---: | ---: | ---: | --- | --- |
| 第 11 章 | 2321 | 2321 | 82 | 已加载 | 网页会员完整可读 |
| 第 12 章 | 2129 | 2129 | 87 | 已加载 | 网页会员完整可读 |
| 第 10 章 | 2234 | 2234 | 64 | 已加载 | 网页匿名完整可读 |

第 10、11、12 章的相邻 ID 互相对应。第 11、12 章均先获得匿名受限结果，再由账号网页获得全文，没有请求移动端。

此验证覆盖生产读取逻辑与真实网页响应，未覆盖用户已安装 VS Code 扩展中的 SecretStorage 会话和扩展宿主网络环境；不宣称已在安装后的扩展中完成会员验证，也不外推为所有书籍均已实测。

## 导航

- 底部导航原本在正常章节 HTML 中存在，但加载错误页没有章节按钮。修复会员解析可使本例恢复到正常章节页面。
- 新增阅读面板标题栏的上一章/下一章命令及方向图标，按相邻章节上下文启用。
- 底部导航保持固定显示，增加边框，并用可收缩网格适配窄面板。
- 用生产 `getChapterHtml` 和合成正文进行浏览器渲染检查，模拟 320×240 视口。浏览器现有缩放下 CSS 视口为 426×320；截图确认两按钮均可见、未被遮挡，点击分别发出 `previous` / `next`。
- 首章上一章按钮禁用且不发送消息；末章下一章按钮禁用且不发送消息。滚动到正文末尾后导航仍固定在视口底部。
- 导航集成测试覆盖跨卷、首末章、受限章节不覆盖阅读进度，以及标题栏上下文章节状态。未用真实 VS Code UI 截图宣称标题栏已现场验证。
