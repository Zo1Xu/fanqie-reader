# Changelog

## [0.7.11] - 2026-09-17

- 修复了SVIP不能观看十章之后的章节的问题

## 历史移动端诊断（未分发到当前网页版本）

- 修复空响应时阅读诊断仍显示 requests 为空的问题：记录初始化、正文请求和 SDK 准备阶段的失败，包含 HTTP 状态、实际读取字节数、耗时和安全错误分类。
- 补充 0.7.10 恢复后再次失效的实测记录。激活接口返回 success 后正文仍为空；持续访客阅读问题尚未解决，本次诊断修复不代表正文恢复。

## [0.7.10] - 2026-09-07

- 修复已保存访客持续返回 110、刷新原会话仍无法读取的问题：保留本地访客参数，自动重新初始化服务端会话，正文完整验证成功后才保存新状态。
- 恢复失败时保留原状态；重新初始化最多每 24 小时一次，次数限制跨重启保留。新访客首次请求失败及账号权限错误不会触发循环初始化。
- 阅读诊断增加重新初始化时间及结果；使用真实故障访客、同书下一章、跨书和重启复用进行验证。
- 后续长时复测发现原访客再次出现 110 或空响应；以上恢复仅短时有效，不能视为持续阅读问题已解决。

## [0.7.9] - 2026-09-07

- 修复书架把网页目录标记直接显示为“已锁定”的问题；目录按实际读取结果更新，网络或会话错误不显示成章节权限锁。
- 用缓存的完整目录补齐上一章、下一章，支持跨卷和首末章；底部翻页按钮常显。
- 状态 110 单独识别为请求被拒绝，保留原安装标识刷新访问状态、重新初始化阅读组件并重试一次；持续失败时暂停自动请求五分钟。
- 新增“复制阅读诊断”命令，只包含平台、接口路径、时间与状态码，不含账号、设备标识或正文。
- 读取失败时保留上一次成功阅读进度。

## [0.7.8] - 2026-09-07

- 接入独立移动端访客正文：网页受限时自动完成访客初始化、SDK 请求准备、正文密钥初始化和 AES/GZIP 正文处理。
- Windows x64 包内置精简运行组件，无需用户安装 Java、连接手机或提供 APK；按需启动，复用访客状态，空闲后释放。
- 区分空响应、需登录、权限不足、正文不完整和未支持的协议格式；失败时提供对应操作。

- 修正网页锁定章节的提示，区分网页阅读受限与 App 解锁，避免将 App 免费章节描述为必须解锁。

- 默认以访客读取正文；受限时仅使用已保存的账号会话重试一次，以服务端权限结果为准。失效会话不会自动弹出登录。
- 登录面板改为主动点击“登录并同步书架”后显示，可选择“暂不登录”；账号存储不可用时仍可打开公开章节。
- 登录成功后自动重试当前可见的受限章节，同时刷新账号书架。
- 浏览器自动化库在真正启动登录浏览器时才加载，访客启动和阅读不加载该依赖。
- 正文与字体使用匹配的 User-Agent；字体不携带 Cookie，锁定章节不下载字体。
- 补充 Android APK 调用链与真实探测记录；正式插件代码已验证第 11 章独立访客全文读取。

## [0.7.7] - 2026-09-01

### 新增

- 官方登录新增 Chrome、Edge、Brave、Vivaldi、Opera、Arc、Firefox、Chromium 和 macOS Safari 自动发现，覆盖 Windows、macOS、Linux 常见安装位置；Firefox 使用隔离的 Selenium WebDriver 会话。
- 书架树视图新增 VS Code 原生“全部折叠”操作，可一键收起已展开的书籍和卷。
- 侧栏二维码下方新增“扫描不成功？点击这里试试”，仅在主动点击后打开纯白、高对比、整数倍放大的二维码页。

### 改进

- 登录说明优先推荐扫码登录；短信验证码和官方小窗口登录继续作为备用方式。
- 书架条目以 3 个并发请求逐步补全书名和作者，并将元数据缓存到 VS Code 本地存储。
- 将“打开书籍或章节”重命名为“通过 ID 或链接打开”，明确该入口用于打开书架以外的内容。
- 书架请求保持扫码浏览器的实际 User-Agent，并按官网请求使用 JSON Accept 与书架 Referer。
- CI 改为在 Linux、Windows 和 macOS 三平台并行执行检查与测试。

### 修复

- 修复扫码登录过早保存不完整会话，以及后续请求硬编码 Windows User-Agent 导致书架为空的问题。
- 修复退出登录时 Cookie 已缺失便无法完成清理、侧栏状态没有立即刷新的问题。
- 修复底部阅读区与书架刷新使用相同产品图标，导致 Cursor/VS Code 标题栏图标视觉重复的问题。
- 检测并隔离旧测试版 `local.fanqie-reader`，避免与正式发布者版本同时加载时重复注册侧栏按钮或错用另一实例的登录状态。

## [0.7.0] - 2026-08-27

- 新增 macOS Safari 登录支持，使用系统自带 `safaridriver` 创建隔离会话。
- Safari 短信登录触发滑块时结束不可交互的自动化会话，并明确提示改用扫码或 Chromium 浏览器。
- 二维码按原始像素显示并扩大白色静区；Safari 同时显示官方二维码窗口作为扫描回退。

## [0.6.0] - 2026-08-25

- 修复 macOS 无法发现 `~/Applications` 中的浏览器，以及配置 `.app` 路径后无法登录的问题。
- 准备首次 GitHub 与 VS Code Marketplace 公开发布。
- 将扩展许可证统一为 `AGPL-3.0-only`。

## [0.5.4] - 2026-08-25

### Added

- 在 VS Code 底部 Panel 中提供终端风格阅读器。
- 阅读器顶部提示符与三行状态信息在滚动时保持固定。
- 侧边栏扫码、短信验证码和官方窗口登录。
- 个人书架、目录、阅读进度和上下章快捷键。
- 登录状态下始终可见的退出登录入口。

### Security

- 登录 Cookie 使用 VS Code `SecretStorage` 保存。
- 手机号、验证码和密码不写入项目文件。
